# Student Marks Calculator 🧮

A beginner-friendly Python project that calculates a student's total marks, percentage, and pass/fail result.

## Features
- Takes the student's name as input
- Accepts marks for five subjects
- Calculates total marks and percentage
- Displays PASS or FAIL based on subject marks

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python student_marks_calculator-1.py
```

## Concepts Practiced
- Variables and user input
- Lists and loops
- Conditional statements
- Basic calculations
